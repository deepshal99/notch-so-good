# Product Hunt Listing — Notch So Good

## Name

Notch So Good

## Tagline (60 chars)

A tiny 3D coworker in your Mac's notch watches Claude Code

## Description

Meet Peek. He hangs off your MacBook's notch and has one job: watch Claude Code and Codex so you don't have to.

While an agent works, Peek reads along and a ring shows how much of your 5-hour usage is left. When it needs you, he climbs out and the notch opens into a card: what happened, in which project, with the task's name taken from your prompt. Click it and you're back in the right terminal tab.

Approve commands right from the notch (or Ctrl-Opt-A / Ctrl-Opt-D from any app). It only ever approves when you click. Eight finishes, from Obsidian to Gummy. Open source, MIT, nothing leaves your Mac.

brew install --cask deepshal99/tap/notch-so-good
