The world's smallest coworker lives in your Mac's notch.

Meet Chawd. He's a mass of pixels. He lives in your MacBook's notch. And he has one job: watch your coding agent so you don't have to.

What Chawd does

Six things, and one of them is falling asleep on the job.

Watches

A live timer, always glanceable

While your agent works, a black pill extends the notch. Chawd sits on the left, a session timer ticks on the right. No window to check, no tab to switch to.

Tells you

Real completion summaries

When the agent finishes, the notch expands with its actual last message — not a generic "task complete". Click anywhere to land back in the exact terminal tab.

Approves

Permissions without the round trip

When an agent wants to run a command or edit a file, Allow / Always Allow / Deny appear right in the notch. Hotkeys too: ⌃⌥A and ⌃⌥D. Read-only tools auto-approve.

Warns

Usage limits before you hit them

Session and weekly rate-limit bars for both Claude Code and Codex, with "% left" and a reset countdown — read from your own local logins. One warning before the wall.

Multitasks

Every session, grouped by project

Running five agents at once? Hover the pill to see all of them — Claude, Codex, and Gemini badges, own timers, own status dots, plus the subagent tree.

Performs

17 animations, zero chill

Wave, dance, sneeze, peek-a-boo, levitate, yawn, hiccup, spin, stretch. His eyes follow your cursor. Ignore him long enough and he falls asleep, then jolts awake when you return.

How it works

Local sockets and agent hooks. No cloud service, no accounts.

Agent starts  →  Chawd appears
Agent works   →  Chawd does tricks, timer ticks
Agent asks    →  Notch expands with the question
Agent needs ok →  Allow / Deny buttons in the notch
Agent done    →  Completion summary, pill fades

Hooks send events over a local Unix domain socket at /tmp/notchsogood.sock. Permission checks are bidirectional — the hook waits for your answer from the notch. Your prompts, code, and file paths never leave your machine.

Frequently asked questions

The things people actually ask.

How do I know when Claude Code is done?

Install Notch So Good. When a session finishes, your notch expands into a green completion notification showing the agent's actual last message. Click it to jump straight back to the terminal tab that ran the session.

Which AI coding agents does it support?

Claude Code and OpenAI Codex CLI are fully supported — each has its own hook installer. Gemini CLI sessions are detected and badged, but there is no Gemini hook installer yet, so that support is partial. Sessions from different agents get their own badges so you can tell them apart when several run at once.

Do I need a MacBook with a notch?

No. On Macs without a notch, notifications appear centered below the menu bar instead. The notch is nicer, but nothing breaks without one.

Is it free?

Yes — free and open source under the MIT license. No accounts, no subscription, no paid tier.

Does it send my code or prompts anywhere?

No. Your prompts, code, and file paths never leave your machine — hooks talk to the app over a local Unix domain socket at /tmp/notchsogood.sock, and there's no server of ours and no telemetry in shipped builds. One honest exception: if you use the usage-limit bars, the app calls Anthropic's and OpenAI's own usage endpoints about every 10 minutes using your existing local tokens, the same way those CLIs do. That traffic goes to those providers, never to us.

How does it read my usage limits? Is that safe?

It reads your own existing local logins — Claude Code's OAuth credentials via Apple's security tool, and Codex CLI's ~/.codex/auth.json — and calls the same usage endpoints those CLIs already use. Nothing is stored or transmitted anywhere else. macOS will ask for Keychain access once; choose "Always Allow" and it won't ask again.

Why does macOS say the app is from an unidentified developer?

The app is ad-hoc signed but not notarized, because notarization requires a paid Apple Developer account. Installing via Homebrew handles this automatically. For manual installs, run xattr -dr com.apple.quarantine /Applications/NotchSoGood.app.

Does it work with iTerm, Warp, tmux, and the VS Code terminal?

Yes. Clicking a notification focuses the exact terminal tab that started the session, across common terminal apps. tmux sessions work too.

How is this different from a terminal bell or a macOS notification?

A bell is easy to miss and tells you nothing. Standard notifications pile up in Notification Center and interrupt whatever you're doing. This lives in the notch, is glanceable at all times, shows a live timer while the agent works, and lets you approve permission requests without switching windows.

Does it slow down my Mac?

No. It's a native SwiftUI menubar app — no Electron, no browser engine. It idles at effectively zero CPU and only does work when a hook event arrives.

Which macOS versions are supported?

macOS 14 (Sonoma) or later, on both Apple Silicon and Intel Macs.

How do I uninstall it?

Run curl -fsSL https://raw.githubusercontent.com/deepshal99/notch-so-good/main/uninstall.sh | bash — or brew uninstall --cask notch-so-good --zap if you installed via Homebrew.
